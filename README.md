# Kastoria — Καθημερινό πλάνο παραγωγής

Οθόνη παρουσίασης για εργοστάσιο ξύλινων δημιουργιών με **15 άτομα**.

## Παρουσίαση σε πελάτη

```bash
python3 -m http.server 8080
```

Άνοιξε `http://localhost:8080` — ή μοιράσου το link από GitHub Pages / preview του PR.

Η πρώτη οθόνη δείχνει το brand **Kastoria**, το πλάνο της ημέρας και τη ροή σταθμών με demo παραγγελίες.

## Καθημερινή ενημέρωση

Στείλε: ημερομηνία · παραγγελίες · απουσίες · επείγοντα  
→ ενημερώνεται `data/plans/YYYY-MM-DD.json` (+ `data/embed.js` για offline demo).

## Οργανόγραμμα (15)

| # | Ρόλος | Σταθμός |
|---|--------|---------|
| 1 | Υπεύθυνος Παραγωγής | Γραφείο |
| 2 | Σχεδιαστής / CAD | Σχεδιαστήριο |
| 3–5 | Κοπή / CNC | Κοπή |
| 6–9 | Ξυλουργός / Συναρμολόγηση | Συναρμολόγηση |
| 10–11 | Τριβή / Φινίρισμα | Τριβείο |
| 12–13 | Βαφή / Βερνίκι | Βαφείο |
| 14 | Ποιοτικός Έλεγχος | QC |
| 15 | Αποθήκη / Αποστολές | Αποθήκη |
