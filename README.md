# Kastoriafm — Καθημερινό πλάνο παραγωγής

Εργαλείο καθημερινού πλάνου για εργοστάσιο ξύλινων δημιουργιών με **15 άτομα προσωπικό**.

## Τι περιλαμβάνει

- Οργανόγραμμα 15 θέσεων (`data/staff.json`)
- Πλάνο ημέρας σε JSON (`data/plans/YYYY-MM-DD.json`)
- Οθόνη πλάνου για κινητό/εκτύπωση (`index.html`)

## Πώς το χρησιμοποιούμε κάθε μέρα

Στείλε στο agent:

1. **Ημερομηνία**
2. **Παραγγελίες** (πελάτης, προϊόν, στάδιο, προθεσμία, προτεραιότητα)
3. **Απουσίες**
4. **Επείγοντα / ειδικές οδηγίες**

Θα ενημερωθεί το αρχείο `data/plans/YYYY-MM-DD.json` και θα φαίνεται στην εφαρμογή.

## Τοπική προβολή

```bash
python3 -m http.server 8080
```

Άνοιξε `http://localhost:8080`

## Οργανόγραμμα (15)

| # | Ρόλος | Σταθμός |
|---|--------|---------|
| 1 | Υπεύθυνος Παραγωγής | Γραφείο |
| 2 | Σχεδιαστής / CAD | Σχεδιαστήριο |
| 3–5 | Κοπή / CNC | Κοπή |
| 6–9 | Ξυλουργός / Συναρμολόγηση | Συναρμολόγηση |
| 10–11 | Τριβή / Φινίρισμα | Τριβείο |
| 12–13 | Βαφή / Βερνίκι | Βαφείο |
| 14 | Ποιοτικός Έλεγχος | QC |
| 15 | Αποθήκη / Αποστολές | Αποθήκη |

Αντικατέστησε τα «Άτομο 1…15» με πραγματικά ονόματα όταν τα έχεις.
